 ##KEY FEATURES OF EARNIFY

 1. General Feature:-
   User authentication (Login/Register/Logout/jwt token).
   Role-based dashboard for worker and buyer.
   Responsive and user-friendly UI.

2. Task 
   =>Buyers can create new tasks via the "Add New Tasks"     feature.  
  => Workers can view all available tasks in the "TaskList" section and send request for the task submit  
   => Admins can monitor and manage tasks using the "Manage Task" section.

3. Withdrawal System:-
   Workers can request withdrawals of earned rewards via the "Withdrawals" feature

4. Coin Purchase System:-
  Buyers can purchase coins for task adding using the "Purchase Coin" section

5. Role-Based Accessibility:-  
   Certain functionalities like "Add New Tasks" and "Manage Tasks" are restricted to specific roles (Buyers/Admins).  

6. Manage Submissions:-  
   =>Workers can view the status of completed tasks in "My Submissions."  
   =>Admins can review and approve task submissions

7. User Management:-  
    => Admins can add, update, or remove users with full control via the "Manage Users" section.  

8. Real-Time Updates:  
    =>Workers receive updates on task approvals or rejections instantly.  

9. Advanced Filtering:  
   => Workers and buyers can filter tasks based on categories, deadlines, or earnings.  

10. Payment History:  
   =>All users can view detailed payment and transaction history in the "Payment History" page.
